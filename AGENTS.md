# Инструкция для Codex и других агентов

Перед планированием, делегированием или изменением проекта полностью прочитайте
и соблюдайте [`CLAUDE.md`](CLAUDE.md). Это единый актуальный источник сведений
об архитектуре, правах, банковской синхронизации, проверках и процессе
`ветка → commit → push → PR → merge`.

Если фактический код расходится с инструкцией, сначала проверьте историю Git и
production-состояние, затем обновите `CLAUDE.md` в том же PR, что и изменение.

Общение с пользователем, UI, комментарии и сообщения коммитов — на русском.
Пользователь не программист: объясняйте результат простыми словами и давайте
пошаговые инструкции «куда нажать», когда от него требуется действие.

Для независимых частей общей цели создавайте отдельных агентов/задачи,
контролируйте их прогресс и проводите итоговое ревью перед объединением.
